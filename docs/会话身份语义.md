## 四个 id 是什么

| 源 | 载体 | 写者 | 语义 |
|---|---|---|---|
| **payload 真号** | 钩子进程 stdin 载荷 `session_id` 字段 | 平台（每钩子调用注入当前会话号） | **钩子当次的真身**——两宿主（ZCode/DSH）皆然；守卫判等的第一锚点 |
| **env 快照 id** | `CLAUDE_SESSION_ID` / `ZCODE_SESSION_ID`（进程环境） | 平台（会话 shell 快照建立时定格） | 会话**开局时**的身份快照；ZCode 长对话续接后可陈旧（DSH 原生层每钩子进程注入=恒真身） |
| **relay 中继 id** | `regress-guard-session-<md5(project)>.json`（临时区，UserPromptSubmit 每轮原子重写） | 钩子侧（`session_relay.write_relay`） | 最近一轮在本项目说话的会话号（last-writer-wins + 5min 新鲜窗）——**agent 侧 CLI（无载荷语境）的真身代理**；多会话共享项目时会被他会话踩踏（issue#8 实测 2-5min/次） |
| **清单 session 戳 / lease holder** | 清单 frontmatter `session:` / lease 块 | 盖章侧（`plan_approve`，relay 优先） | 清单归属的**登记事实**，判等的对照面 |

## 判等规则（守卫侧，`session_relay.my_sids` 单一实现）

1. **payload 在场（钩子进程）**：身份集 = {payload} ∪ {env 若在}——
   payload 是当次真身锚点；env 保留兜 ZCode 续接旧戳清单（env 是自有
   谱系旧号，从不是他会话号，弃 env=双 id 自拦回归）。**relay 不进集**：
   其「无载荷语境猜真身」使命已被 payload 取代，且 DSH 多会话下 relay
   携他会话噪音（误拦与误放双向根治）。
2. **无 payload（agent 侧 CLI 等）**：身份集 = {env} ∪ {新鲜 relay}
   **并集，冲突不弃 env**——批218「冲突以 relay 真身为准 env 即弃」的
   前提（env 恒陈旧）是 ZCode 续接特例；DSH 每进程 env 皆真身，弃 env
   =弃真身→自己拦自己（issue#8 主诉）。
3. **单源**：任一源单独在场即该源为身份（relay 无 id 冷啔回退 env）。
4. **新鲜窗**：relay 仅 5min 内有效；窗外=陈旧中继不得代言。
5. **只读判等**：守卫侧判等不写回 relay、不继承进持久化戳（防中继回翻污染）。

## 写入规则（盖章侧）

- 清单 session 戳 / lease holder 一律 **relay 优先、env 兜底**
  （`plan_approve`：`read_relay(...).sid or sid_from_env()`）。
- 守卫侧任何代码**不得**写 relay（写者只有 UserPromptSubmit 钩子）。

## 已知边界（backlog）

- 无 payload 路径的并集含他会话新鲜 relay=**误放窗口**（有界 5min，
  批218 前既有语义；issue#8 后 payload 路径已根治，残留面=纯 CLI 语境）。
- 治本方向（backlog 不变）：单调序号 relay / relay 写者指纹 / shell
  快照 env 刷新。
